## Features

* Red color segmentation in HSV space
* Morphological mask filtering
* Object detection using image moments
* Object center and radius estimation
* Horizontal offset visualization
* Video-based object tracking

## Technologies

* Python
* OpenCV
* NumPy

## How to run

pip install opencv-python numpy  
python main.py --video your_video_file.mp4
